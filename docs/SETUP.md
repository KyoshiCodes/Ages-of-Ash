# Native Windows setup

Use `pnpm run doctor`: pnpm 12 has a built-in `doctor` command that otherwise takes precedence over this repository's preflight script. `pnpm doctor` checks pnpm itself and does not validate PostgreSQL or this game.

1. Use Windows 10 22H2 (build 19045+) or Windows 11. Reserve 10 GB disk, 4 GB free RAM. Open PowerShell in `C:\Projects\Ages of Ash`. Install missing tools using `winget install -e --id Volta.Volta`, `winget install -e --id Git.Git` and optionally `winget install -e --id GitHub.cli`. Restart the terminal after installation.
2. Run `volta install node@24.21.0` and `volta install pnpm@12.5.1`. Run `Get-Command node,pnpm -All`; Volta must precede older installations. `node --version` must show 24.21.0 or a newer 24.x patch. This repository pins 24.21.0 and pnpm 12.5.1.
3. Install PostgreSQL using `winget install -e --id PostgreSQL.PostgreSQL.18`. In the native EDB installer select server, command line tools and pgAdmin; use port 5432 and record the postgres password in your password manager. Apply patch 18.6 or later within 18.x. Run `Get-Service *postgres*`; start the service in an administrator terminal if necessary. Add `C:\Program Files\PostgreSQL\18\bin` to your user PATH, then reopen PowerShell.
4. Clone the canonical repository if not already in this workspace: `git clone https://github.com/KyoshiCodes/Ages-of-Ash.git`. Enter its directory. Run `git config core.autocrlf false`. The checked-in attributes enforce LF.
5. Run `Copy-Item .env.example .env`. Edit `.env`: set a private app password in DATABASE_URL and set PG_ADMIN_URL to `postgresql://postgres:YOUR_URL_ENCODED_PASSWORD@localhost:5432/postgres`. Percent-encode special characters in URL passwords. This admin URL is used only for bootstrap; remove it after successful setup. The app role is deliberately not a superuser.
6. Run `pnpm install`, then `pnpm run doctor`. Resolve printed failures. Doctor never installs system prerequisites. `pnpm run doctor --fix` performs only project tool pinning, dependencies, database bootstrap/probe, Prisma generation, migrations and seed. `pnpm setup:db` creates the configured role/database only when missing and when PG_ADMIN_URL is supplied; existing passwords are never overwritten. Checked-in migrations use migrate deploy; new migration authors use `pnpm db:migrate --name meaningful_change` with a separately provisioned shadow database.
7. Run `pnpm exec playwright install chromium`. Recommended VS Code extensions are in `.vscode/extensions.json`. Run `pnpm verify`, then `pnpm dev`. Keep that PowerShell terminal open.
8. You should now see the **Ages of Ash — The Ember Ledger** login screen at http://localhost:5173. Enter as a guest. The dossier shows four clocks, an operation button, crew, holdings and a boss. Run an operation: cash, XP, mastery and energy change and the activity feed confirms the server result. Open another profile for live multiplayer. `pnpm test:e2e` verifies the main loop; stop pnpm dev first to free ports.

Expected development RSS (estimates, measure on your machine): PostgreSQL 150–350 MB with 128 MB shared_buffers, API 100–200 MB, worker 90–180 MB, Vite 150–350 MB. Browser 200–500 MB. Compilation can briefly add 500 MB; do not run several verification suites simultaneously. The GPU is unused.

| Symptom                            | Fix                                                                                                                                                                                                                                          |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 5432 occupied by older server      | `Get-NetTCPConnection -LocalPort 5432` then `Get-Process -Id <PID>`; stop only the old service you own, or change both installer port and DATABASE_URL.                                                                                      |
| pg_hba.conf rejects authentication | In PostgreSQL 18 data directory, add narrowly scoped localhost IPv4/IPv6 rules for ages using scram-sha-256; reload using pgAdmin. Do not use trust for normal operation.                                                                    |
| Forgotten postgres password        | Use another authorized database administrator to reset it; otherwise follow the EDB password recovery process with local administrative access, temporary localhost-only recovery configuration, and immediate restoration of scram-sha-256. |
| psql missing                       | Add `C:\Program Files\PostgreSQL\18\bin` to user PATH; reopen terminal.                                                                                                                                                                      |
| Wrong Node version                 | `Get-Command node -All`; move Volta shims ahead of old Node entries in Environment Variables, reopen terminal, `volta pin node@24.21.0`.                                                                                                     |
| .ps1 blocked                       | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`; use `Unblock-File .\scripts\bootstrap-repo.ps1` after reviewing it.                                                                                                                   |
| Defender locks node_modules        | Close dev processes and retry install after scanning completes; inspect Protection History. Do not disable protection globally.                                                                                                              |
| EPERM / long paths                 | Keep checkout short; admin terminal: `git config --system core.longpaths true`; `pnpm config set store-dir C:\pnpm-store`; retry install.                                                                                                    |
| Prisma engine download fails       | Check corporate proxy/CA and HTTPS access to Prisma downloads; configure your trusted certificate, retry `pnpm db:generate`. Never disable TLS verification.                                                                                 |
| Stale Prisma client                | `pnpm db:generate`, restart API and worker after schema changes.                                                                                                                                                                             |
| Shadow database denied             | Use checked-in `pnpm setup:db`; migration authors configure a separate shadow database and Prisma config, never grant runtime superuser.                                                                                                     |
| WebSocket disconnected             | Ensure API port 3000 is running; Vite proxies /api and /live, and APP_ORIGIN exactly matches browser origin.                                                                                                                                 |

Version evidence checked during build: [Node releases](https://nodejs.org/en/download), [pnpm registry](https://registry.npmjs.org/pnpm/latest), [PostgreSQL 18](https://www.postgresql.org/docs/18/release.html). Exact installed package resolutions are captured in pnpm-lock.yaml.

For maintainers only: `scripts/test-native-db.ps1` can use the official [EDB native Windows archive](https://www.enterprisedb.com/download-postgresql-binaries) extracted at `.local/postgresql/pgsql`. It initializes an isolated SCRAM test cluster on port 55432, runs migrations and the integration/browser suite, then stops that cluster. This was used for verification on this workspace; it does not install or replace your normal PostgreSQL service. The test script never downloads or installs anything. Treat the test database as disposable and do not point production traffic at it.
